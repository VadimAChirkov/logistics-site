Calculation of customs payments

Below is the algorithm for calculating customs duty and VAT on the importation of goods into the customs territory of Russia, with a real example.

Calculation algorithm

  1. Determine the customs value (CV) = value of the goods + cost of carriage to the EAEU border + insurance.
  2. Calculate the import duty = CV × duty rate (by TN VED code).
  3. Calculate VAT = (CV + duty) × VAT rate (usually 20%).
  4. Total payments = duty + VAT (+ customs fees for operations).
An important nuance: the customs value includes carriage only up to the EAEU border. Carriage within the customs territory (for example, Vladivostok → Moscow) is not included in the CV where it is itemised separately in the documents and not included in the price of the goods. Including the full freight to the final destination in the CV is a frequent mistake leading to overpayment of VAT.

A real example

Product: Deye SUN-6K-SG05LP1-EU-SM2-P hybrid solar inverter, 6 kW.

Delivery: Shanghai → Moscow, one 20-foot container.

Initial data

ParameterValue
TN VED code8504 40 840 0 (static converters ≤ 7.5 kVA)
Import duty rate0%
VAT rate20%
Value of the goods in the containerRUB 3,453,750
Freight Shanghai → VladivostokUSD 3,500
CBR exchange rate (on the settlement date)82.9803 RUB/USD

Step 1. Freight in rubles

3,500 × 82.9803 = RUB 290,431.05

Step 2. Insurance premium

Insurance base = freight + value of the goods = 290,431.05 + 3,453,750 = RUB 3,744,181.05.

Insured amount = base × 110% = 3,744,181.05 × 1.10 = RUB 4,118,599.16.

Insurance premium = insured amount × 0.5% = 4,118,599.16 × 0.005 = RUB 20,593.00.

Step 3. Customs value

CV = goods + freight to the border + insurance = 3,453,750 + 290,431.05 + 20,593.00 = RUB 3,764,774.05.

Step 4. Import duty

CV × 0% = RUB 0.

Step 5. VAT

(CV + duty) × 20% = 3,764,774.05 × 0.20 = RUB 752,954.81.

Result

PaymentAmount
Import dutyRUB 0
VAT 20%RUB 752,954.81
Total customs paymentsRUB 752,954.81
Customs operations fee (for reference)~RUB 7,500

The importer's full cost (goods + freight + insurance + VAT) ≈ RUB 4,517,729 — excluding the Vladivostok → Moscow carriage.

Note: the calculation is given for educational purposes. Rates, exchange rates and thresholds may change — before a shipment, verify them against current data (EAEU TN VED, the Common Customs Tariff, the CBR exchange rate).
