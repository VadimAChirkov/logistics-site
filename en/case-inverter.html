Solar inverter from China: where the non-tariff rules hide

A solar inverter with Wi-Fi and Bluetooth looks like a "hard import": almost everyone immediately thinks of FSB notification, radio-frequency permits and encryption. In reality it is the opposite — this example shows exactly where non-tariff regulation applies and where it does not.

Product and classification

Hybrid inverter (grid-tie + off-grid, with MPPT for batteries) Deye SUN-6K-SG05LP1-EU-SM2-P, 6 kW: PV input 370–500 V DC, battery input 48 V, output 220/230 V AC; built-in Wi-Fi module (remote monitoring, WPA2/WPA3 encryption) and Bluetooth for local setup. Country of origin — China.

HS code: 8504 40 850 0 — "static converters (inverters)". Import duty on this code is 0%, VAT at the current rate. The same inverter and code are used in the example on the "Customs payments calculation" page.

Step 1. Two declarations of conformity

The inverter falls under two EAEU technical regulations, and the conformity form for both is a declaration of conformity:

  1. TR CU 004/2011 (low-voltage equipment safety): the inverter falls into the class "electrical machines and equipment 50–1000 V AC / 75–1500 V DC" — this class requires declaration (Art. 7 of the regulation).
  2. TR CU 020/2011 (electromagnetic compatibility): the inverter is "a technical device capable of creating electromagnetic interference" → declaration.

The conformity form for a solar inverter is a declaration, not a certificate: this product is not on the mandatory certification lists.

What is not required. TR EAEU 037/2016 (RoHS, restriction of hazardous substances) does not apply to solar inverters: on the 8504 codes this regulation lists only low-power UPS (8504 40 300 4 / 8504 40 300 8), not solar inverters (8504 40 850 0).

Step 2. The radio part: import without a licence

Wi-Fi (IEEE 802.11) and Bluetooth (IEEE 802.15) in the 2400–2483.5 MHz band are short-range devices. They are in the unified register of radio-electronic devices for which no licence or approval is required on import. The parameters (band, power) are confirmed by the manufacturer's documentation.

Step 3. The crypto part: no FSB notification required

Formally, Wi-Fi uses encryption (WPA2/WPA3, AES), so the inverter "contains encryption (cryptographic) means". But FSB notification applies to goods listed in section 2.19 of the list (EEC Board Decision No. 30 of 21.04.2015). That list covers computers (8471), telecom equipment (8517), TV/radio equipment (8525–8528), integrated circuits (8542) and "other machines with individual functions" (8543). Code 8504 is not in section 2.19.

Therefore the inverter (8504 40 850 0) is not subject to FSB notification — even with built-in encrypted Wi-Fi. Notification is required for routers, smartphones, cameras, TV boxes (codes 8517, 8528, etc.), but not for static converters.

Having Wi-Fi ≠ needing FSB notification. The HS code and the list (section 2.19) decide, not the presence of a radio module.

Where the non-tariff regulation really hides

The classification trap. Code 8504 40 850 0 is "borderline": it appears in mandatory certification lists for similar products — UPS for PCs (TR CU 004, 020), UPS for fire alarm systems (TR EAEU 043/2017), power converters over 5 kW for railway rolling stock (TR CU 001/2011). A correct description of the product's purpose (solar inverter, not a UPS) is the key to using a declaration instead of a certificate.

Final document package for the importer

  1. Declaration TR CU 004/2011.
  2. Declaration TR CU 020/2011.
  3. Radio import licence/approval — not required (short-range device, 2.4 GHz).
  4. FSB notification — not required (8504 is not in section 2.19).
  5. Customs declaration, code 8504 40 850 0 (duty 0%), with a correct description of the product's purpose.

Practical takeaways

  • "Has Wi-Fi" ≠ "needs FSB notification". The HS code and the list (section 2.19) decide, not the presence of a radio module.
  • Check the applicability of each regulation and permit against the official list (code + purpose), not by analogy with similar goods.
  • Classify the goods carefully: the correct code determines the whole set of documents.
