📈 Рыночные индексы — изменение

SCFI — Shanghai Containerized Freight Index

Композитный индекс контейнерных фрахтовых ставок, публикуемый Шанхайской биржей судоходства (Shanghai Shipping Exchange) раз в неделю (по пятницам). Отражает средние спотовые ставки на перевозку контейнеров из Шанхая по основным направлениям (Европа, Средиземноморье, обе Америки и др.). Главный ориентир для ставок на экспорт из Китая.

Drewry WCI — World Container Index

Композитный индекс контейнерных ставок компании Drewry, публикуемый раз в неделю (по четвергам). Рассчитывается как средняя ставка (в USD) за 40-футовый контейнер (FEU) по 8 ключевым торговым путям. Широко используется в договорах с индексацией ставок.

BDI — Baltic Exchange Dry Index

Индекс стоимости фрахта сухогрузного тоннажа, публикуемый Балтийской биржей (Baltic Exchange, Лондон) ежедневно. Отражает ставки на перевозку сухих навалочных грузов (руда, уголь, зерно) по основным маршрутам; состоит из субиндексов Capesize, Panamax и Supramax. Ключевой индикатор рынка сухогрузных перевозок.
