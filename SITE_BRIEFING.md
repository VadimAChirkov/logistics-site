## 4. Рыночные индексы (главная страница)

**Три индекса** в `market-data.js`:
1. **SCFI** (Shanghai Containerized Freight Index) — значение 3633.45, **пункты** (НЕ USD). Источник sse.net.cn, по пятницам.
2. **Drewry WCI** (World Container Index) — $4 389, **USD/40ft** (единственный в USD). Источник drewry.co.uk, по четвергам.
3. **BDI** (Baltic Exchange Dry Index) — 2 862, **пункты** (НЕ USD). Источник balticexchange.com, ежедневно.

**Обновление — вручную еженедельно:** правишь значения в `market-data.js`, обновляешь поле `updated`, коммит + push.

**Где показывается:**
- Компактная строка под шапкой справа (`#indices-strip`).
- Виджет-таблица «Рыночные индексы — изменение» (`#indices-widget`) с колонками: Индекс / Значение / Изменение / На дату.
- Под таблицей — текстовые описания трёх индексов.

## 5. Новости (главная страница)

- Данные в `news-data.js`, рендер в `#news-widget`.
- **Обновление автоматическое:** GitHub Actions (`update-news.yml`) каждые 6 часов запускает `scripts/fetch_news.py`, который тянет RSS из Splash 247, The Loadstar, РЖД-Партнер, SeaNews, пишет `news-data.js` и коммитит.
- Источники указаны под виджетом.
